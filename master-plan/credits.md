# Photo credits

All photos come from the Open Images Dataset (Google), which indexes Flickr photos
published under the Creative Commons Attribution 2.0 licence (CC BY 2.0). Pexels,
Unsplash and Openverse were unreachable from the build environment, so this was the
only licensed source available. CC BY 2.0 allows commercial use with attribution:
keep this file with the deck, or add a small credits line on the closing slide.

Note on resolution: Open Images serves copies downscaled to 1024 px on the long side,
so crops are 480 to 1024 px wide. They hold up on screen under the dark scrims but
will look soft on a very large display or in print. To upgrade, download the original
from each Flickr URL below (same licence, higher resolution) and drop it into
`photos/<slot>.jpg`, then rebuild.
